# Рыжик — приключение котика

Браузерная игра без сборки и серверной части. Для запуска откройте `index.html` в браузере.

Также можно запустить локальный сервер из корня репозитория:

```sh
python3 -m http.server 8000
```

Игра будет доступна по адресу <http://localhost:8000/games/ginger/>.

## Файлы

- `index.html` — экраны и элементы управления.
- `css/game.css` — оформление, включая мобильные кнопки.
- `js/game.js` — состояние игры, управление, физика и отрисовка мира.
- `js/levels.js` — темы, разметка восьми уровней и оформление их карточек. В карте уровня `#` — платформа, `~` — вода, `S` — пружина.
- `js/audio.js` — музыка и звуковые эффекты.
- `js/cat.js` — отрисовка Рыжика.

Прогресс и настройка звука хранятся в `localStorage` браузера под ключом `ryzhik_v1`. Шрифты загружаются через Google Fonts; при отсутствии сети используются системные шрифты.

## Проверка проходимости отдельных препятствий

```sh
node --test games/ginger/tests/gameplay.test.cjs
```

Тесты выполняют настоящую физику игры в упрощённом окружении без браузера: проверяют пружину и переход через воду на втором уровне, прыжок через последние шипы к финишу на четвёртом две лужи на шестом, включая лужу после чекпойнта, а также платформы и финиш на седьмом. Отдельно проверяется срабатывание финиша на его высоте во всех уровнях. Это проверки отдельных участков, а не автоматическое прохождение всех уровней целиком.
