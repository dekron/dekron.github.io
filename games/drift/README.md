# NEON DRIFT — синтвейв-гонки

Браузерная игра без сборки и серверной части. Для запуска откройте `index.html` в браузере.

Также можно запустить локальный сервер из корня репозитория:

```sh
python3 -m http.server 8000
```

Игра будет доступна по адресу <http://localhost:8000/games/drift/>.

## Правила

Газ автоматический. Проезжай ворота, пока не растаял таймер: каждые ворота дают +время.
Дрифт (SPACE) заряжает нитро, нитро (E) разгоняет машину выше обычного предела.
С края эстакады можно упасть — машина вернётся к последним пройденным воротам.
Три звезды: финиш, без падений, дрифт-мастер (5+ секунд в скольжении).

## Файлы

- `index.html` — экраны и элементы управления.
- `css/game.css` — оформление, включая мобильные кнопки.
- `js/track.js` — грамматика ритма и генератор трасс: фразы (дуги, шпильки, шиканы, мосты)
  собираются в центральную линию эстакады. Курс ограничен конусом ±1.25 рад от «вверх»,
  поэтому трасса монотонна по Y и никогда не пересекает саму себя. Seed детерминирован.
- `js/audio.js` — синтезованный саундтрек: темп, яркость фильтра и арпеджио привязаны к скорости;
  мотор и визг покрышек — непрерывные слои WebAudio.
- `js/car.js` — отрисовка машины.
- `js/game.js` — состояние, физика дрифта (продольная/поперечная скорость, сцепление),
  камера, частицы и рендер мира.

Рекорды и настройка звука хранятся в `localStorage` под ключом `neondrift_v1`.
Шрифты загружаются через Google Fonts; при отсутствии сети используются системные.

## Проверка физики и генератора

```sh
node --test games/drift/tests/gameplay.test.cjs
```

Тесты выполняют настоящую физику игры в упрощённом окружении без браузера: детерминизм
и валидность трасс (включая 20 случайных seed), разгон и руление, заряд нитро дрифтом,
расход нитро, падение с края и возврат к чекпойнту, бонус времени за ворота, столкновение
с барьером, финиш и таймаут. Это проверки отдельных механик, а не автоматическое
прохождение трасс целиком.
