# День 0 — сайт Дмитрия Воронина

Статический сайт: сборка и установка зависимостей не нужны. Внешний вид, очередь проектов, инструменты и игра работают на HTML, CSS и JavaScript.

## Запуск на компьютере

Откройте терминал в папке проекта и выполните:

```sh
python3 -m http.server 8000
```

Перейдите на <http://localhost:8000/>. Запуск через сервер необходим: браузеры не загружают JavaScript-модули при открытии `index.html` напрямую через `file://`.

## Публикация на GitHub Pages

1. Загрузите в репозиторий `index.html` и папку `assets` целиком, сохранив структуру файлов.
2. В настройках репозитория откройте **Pages** → **Build and deployment**.
3. Выберите **Deploy from a branch**, нужную ветку и папку `/ (root)`, затем сохраните.
4. После публикации откройте адрес, который покажет GitHub Pages. Пути к файлам относительные, поэтому сайт работает и в репозитории-проекте с адресом вида `username.github.io/repository/`.

## Где что находится

- `index.html` — разметка и тексты основных разделов.
- `assets/css/` — базовое оформление, разделы, модальные окна и адаптивные стили. Файлы подключены именно в этом порядке.
- `assets/js/content.js` — очередь проектов и записи дневника; `covers.js` — их SVG-обложки.
- `assets/js/snake.js` — игра GRID RUNNER; открывается в модальном окне и очищает обработчики при закрытии.
- `assets/js/scene.js` и `rain.js` — 3D-сцена и фоновый эффект; `main.js` — взаимодействия страницы; `utils.js` — общие функции.
- `assets/js/bootstrap.js` — защита от зависания стартового экрана при ошибке загрузки.

Адрес `hello@dvoronin.dev` указан в разметке и в `assets/js/main.js`; перед публикацией проверьте, что он вам подходит. Формы не отправляют данные на сервер: они создают черновик письма и сохраняют его данные в браузере посетителя. Письмо отправляет сам посетитель через свой почтовый клиент.

Шрифты загружаются с Google Fonts, а Three.js — с CDN. При недоступном Three.js сайт продолжит работать, но 3D-ядро заменится заглушкой и его настройки будут отключены.
